# Electrotecnia Completa: Corriente Directa y Alterna

> **Una guía definitiva, clara y completa sobre todos los conceptos de circuitos eléctricos.**
> Desde cero hasta análisis avanzado, sin excepciones.

---

## Cómo usar esta guía

Cada archivo es **autosuficiente**. Puedes leerlos en cualquier orden, pero el camino recomendado es:

```
Fundamentos → Corriente Directa → Corriente Alterna → Ejercicios → Fórmulas → Referencias
```

Cada sección incluye:
- **Explicación clara** con analogías del mundo real
- **Fórmulas** explicadas paso a paso
- **Ejemplos resueltos** con números
- **Verificaciones** para que compruebes tu respuesta
- **Ejercicios propuestos** con respuestas al final

## Convenciones usadas

- **Definición**: concepto nuevo explicado con palabras simples
- **Fórmula**: ecuación con cada variable explicada
- **Ejemplo**: problema resuelto con números concretos
- **Verificación**: cómo comprobar que tu respuesta es correcta
- **Analogía**: comparación con algo cotidiano para entender mejor
- **⚠️ Error común**: errores frecuentes que debes evitar
- **💡 Tip**: consejos prácticos y atajos
